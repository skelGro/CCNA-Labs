### Key Insights & CLI Commands Learned (Day 4)

Instead of just passively following the video steps, I got the most value by breaking down configurations and troubleshooting errors independently in the CLI.

#### Core Commands Practiced:
- `enable` – Transition from User EXEC to Privileged EXEC mode.
- `configure terminal` (`conf t`) – Enter Global Configuration mode.
- `hostname <name>` – Assign a unique device identifier.
- `enable password` / `enable secret` – Configure privileged mode access (tested difference between cleartext and encrypted hashing).
- `interface <id>` & `ip address <ip> <mask>` – Assign IP addressing and bring up interfaces (`no shutdown`).
- `show running-config` & `show ip interface brief` – Verify active configuration and interface status.
